# Customer Shopping Behavior Analysis

## 1. Overview

This project focuses on analyzing customer shopping behavior to identify purchasing patterns, customer segments, product preferences, subscription trends, and revenue insights.

The objective is to transform raw customer shopping data into meaningful business insights using Python, SQL, and Power BI.

The project follows an end-to-end data analytics workflow, starting with data loading and cleaning, followed by Exploratory Data Analysis (EDA), SQL-based analysis, dashboard development, and business reporting.

## 2. Dataset

- **Dataset:** Customer Shopping Behavior
- **Total Records:** 3,900 rows
- **Total Columns:** 18
- **Data Type:** Customer demographics, shopping transactions, and purchasing behavior.

### Key Features

- Customer demographics (Age, Gender, Location)
- Product details (Item Purchased, Category)
- Purchase Amount
- Subscription Status
- Season and Shipping Type
- Review Rating
- Discount and Promotional Usage
- Purchase Frequency

### Data Quality

- Identified 37 missing values in the Review Rating column.
- Handled missing values using median ratings based on product categories.
- Removed redundant columns after consistency checks.
- Standardized column names for better readability.

## 4. Project Workflow

### Step 1: Data Loading
- Imported the dataset into Python using Pandas.
- Inspected the dataset using `head()`, `info()`, and `describe()`.
- Reviewed column names, data types, and data quality.

### Step 2: Exploratory Data Analysis (EDA)
- Analyzed customer demographics.
- Explored purchasing patterns and spending behavior.
- Examined product categories and customer preferences.
- Investigated subscription and discount trends.
- Identified patterns across age groups and shipping types.

### Step 3: Data Cleaning & Feature Engineering
- Handled missing values in Review Rating.
- Renamed columns using snake_case.
- Removed redundant columns after consistency checks.
- Created age groups:
  - Young Adult
  - Middle-aged
  - Adult
  - Senior
- Created a purchase frequency feature to understand customer purchasing behavior.

### Step 4: SQL Analysis

Loaded the cleaned dataset into SQL databases and performed business-oriented queries using PostgreSQL, MySQL, and SQL Server (SSMS).

Key business questions included:

- What is the total revenue generated by each gender?
- How do subscribers and non-subscribers compare?
- Which products have the highest average ratings?
- How does shipping type affect purchase amounts?
- Which products are most dependent on discounts?
- What are the different customer segments?
- Which products generate the highest revenue within each category?
- How does purchase behavior vary across age groups?

## 6. Key Results & Business Insights

The analysis revealed several important insights:

**1. Revenue by Gender**
- Male customers generated $157,890 in revenue.
- Female customers generated $75,191 in revenue.

**2. Subscription Analysis**
- 1,053 customers were subscribers.
- 2,847 customers were non-subscribers.
- Average spending was relatively similar across both groups.

**3. Customer Segmentation**
- Loyal Customers: 3,116
- Returning Customers: 701
- New Customers: 83

**4. Top-Rated Products**

The five highest-rated products were:
- Gloves: 3.86
- Sandals: 3.84
- Boots: 3.82
- Hat: 3.80
- Skirt: 3.78

**5. Discount Analysis**

Products with the highest discount rates included:
- Hat: 50.00%
- Sneakers: 49.66%
- Coat: 49.07%
- Sweater: 48.17%
- Pants: 47.37%

**6. Shipping & Repeat Purchases**
- Standard Shipping Average Purchase: $58.46
- Express Shipping Average Purchase: $60.48
- Repeat Buyers (more than 5 purchases): 958

## 7. Business Recommendations

Based on the analysis, the following recommendations were identified:

- **Increase Subscriptions:** Introduce exclusive subscriber benefits to improve subscription adoption.
- **Strengthen Customer Loyalty:** Develop loyalty programs and rewards for repeat customers.
- **Optimize Discount Strategies:** Review discount policies for products with high discount dependency.
- **Improve Product Marketing:** Promote highly rated and popular products.
- **Personalized Marketing:** Target customer age groups and purchasing segments with relevant offers.
